# Project AD

- 간단한 3D 로그라이트 게임 프로토타입 만들기

복셀 디자인 생각 중

천사 또는 악마가 전투 시뮬레이션을 진행
천사 - 근접(망치) 전투
악마 - 중~원거리(마법) 전투

## 게임 구조
1. 게임 시작
2. 캐릭터 선택
3. 층 진행
4. 몬스터 처치 및 레벨 업(모듈 장착)
5. 다음 층 진행
6. 반복 후 보스 전투
7. 클리어

조작
 WASD 이동 / 마우스 캐릭터방향 및 공격

## 현재 목표
- 플레이어 따라가는 ENEMY 만들기
- 간단한 ENEMY 공격 만들기
- 플레이어 게임 오버 구현
- 한 층 플레이 만들기
